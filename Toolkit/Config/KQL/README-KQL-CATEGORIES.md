# Shadow Trace Ops KQL Category Structure

## Current Recommended Categories

### EmailAttack
- Campaign analysis
- Sender/domain analysis
- Attachment campaigns
- Spray-and-pray patterns
- Spoofing detection

### EmailUrlActivity
- Email-to-click correlation
- User URL interaction
- Phishing click tracking
- Email delivery followed by user interaction

### Endpoint
- Device logons
- Process execution
- Network activity
- Remote interactive/RDP activity

### Identity
- Sign-ins
- Risk events
- Legacy auth
- Unmanaged device access
- Rare locations

### CloudApps
- SaaS activity
- File sharing
- Session activity
- OAuth actions
